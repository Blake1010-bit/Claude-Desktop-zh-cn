# Claude Desktop 界面汉化 — 翻译规则

你要把 Claude Desktop 应用界面的英文文案翻译成**简体中文（zh-CN）**。

## 硬性规则（违反任一条都会破坏界面）

1. **只翻译英文文本本身**。绝不翻译、改写、增删 JSON 的键（键是不透明哈希，必须逐字节照抄）。
2. **完整保留每一个 `{placeholder}`**，包括花括号和拼写。
   例：`{name}` 保持 `{name}`；`{fileName}` 保持 `{fileName}`。
3. **保留 ICU MessageFormat 结构**，只翻译花括号内可读的文本。
   例：`{count, plural, one {# file} other {# files}}`
   译为：`{count, plural, one {# 个文件} other {# 个文件}}`
   关键字 `plural` / `select` / `selectordinal` / `=0` / `=1` / `one` / `other` / `few` / `many`
   以及 `#` 符号必须原样保留。绝不合并或调换分支。
4. **保留 XML 风格标签**，只翻译标签内部的文字。
   例：`<link>Read more</link>` 译为 `<link>了解更多</link>`。
   标签名、斜杠、属性一律不变。
5. **保留首尾空格、`\n` 换行转义和标点结构**。
6. **不翻译产品名**：Claude、Claude Code、Claude Desktop、Anthropic、Cowork、Artifacts、
   MCP、GitHub、Slack、Google Drive、VS Code、macOS、Windows。
7. **使用自然、简洁的界面中文**——像一个打磨过的中文软件界面，不要逐字硬译。
8. **译文要短**，按钮、菜单、标签不能溢出。
9. 英文句子内部的逗号、句号转用**全角中文标点**（，。：？！）；
   代码、路径类文本保持半角标点。

## 输出要求

- 输出一个 JSON 对象，**键与输入完全一致**（数量、拼写都不许多不许少）。
- 值为对应的简体中文译文。
- 只输出 JSON 文件内容，不要加任何解释、markdown 代码围栏或注释。
- 文件较大时，先用 Write 写入一部分，再用 Edit 分多次追加，确保最终文件是**完整合法**的 JSON。
- 写完后必须自行校验：能否被 JSON 解析、键数是否与输入一致。

## 自检清单（写完必须核对）

- [ ] 键集合与输入**逐一对应**，没有遗漏、没有多出、拼写无偏差
- [ ] 所有 `{...}` 占位符在译文中**原样出现**
- [ ] 所有 `<tag>...</tag>` 标签名未被翻译
- [ ] 没有把值留成英文原文（除非该值本身就是产品名或纯符号）
- [ ] 文件是合法 JSON
